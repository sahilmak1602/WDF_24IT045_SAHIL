# itue301-exam-24it045-A

FitZone Gym & Class Booking System — Set B.

## Run

### Backend
```bash
cd backend
npm install
npm run dev
```

Backend runs on http://localhost:5000

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Frontend runs on http://localhost:5173

## MongoDB
Create `backend/.env` from `.env.example` and put your MongoDB Atlas connection string there.
